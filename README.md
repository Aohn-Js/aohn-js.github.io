## Cómo correrlo en local

No requiere instalación ni build. Cloná el repo y abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor estático:

```bash
git clone https://github.com/Jxssper/Jxssper.github.io.git
cd Jxssper.github.io
# con Python
python3 -m http.server 8000
# o con la extensión Live Server de VS Code
```
